# 开始页面与制作人员名单

## 开始页面：TitleScene.unity

在 Hierarchy 展开 Canvas，选中以下物体，将精灵拖到 Inspector 的 Image → Source Image：

| 物体 | 放置素材 |
| --- | --- |
| Backdrop | 原有开始页面背景 |
| TitleImage | 大标题图 |
| StartButton | 开始游戏按钮图 |
| SettingsButton | 设置按钮图 |
| QuitButton | 退出游戏按钮图 |

复用原有开始页面与按钮布局，新增 TitleImage 使用精灵；旧文字标题继续保持关闭。新增标题槽位未替换素材时透明。Image 的 Color 保持白色、不透明即可。标题与按钮保持图片比例，原有背景和按钮布局保留；位置、尺寸在各自 Rect Transform 中调整。

按钮已接线：开始游戏进入 Level1，设置打开现有设置面板，退出在编辑器中停止 Play、打包后退出程序。设置中的返回主界面会回到 TitleScene。

按钮已使用 Sprite Swap。若有悬停图，可在 Button → Sprite State 的 Highlighted Sprite、Selected Sprite 中拖入；按下图放在 Pressed Sprite。

TitleSystems → Title Menu 中可调整 Title Swing Degrees（默认左右各5°）和 Title Swing Period（默认2.4秒一周期）。Title Graphic 已连接 TitleImage，不需要重新接线。

## 名单页面：Credits.unity

在 Canvas 下依次选择 CreditsImage01、CreditsImage02、CreditsImage03、CreditsImage04，把四张制作人员名单精灵分别放进 Image → Source Image。四个物体叠在同一位置是正常的，播放时脚本会控制透明度。

CreditsController → Credits Sequence 的 Slides 已按01—04连接，不需要替换这些 Image 引用，只换每个 Image 的 Source Image。

- Hold Seconds：每张完全显示的停留时间，默认4秒。
- Fade Seconds：渐入、图片间渐变与最后渐出的时间，默认1秒。
- 默认总长约21秒。播放一轮后返回 TitleScene，不循环。

第三章最后一句结束后自动进入 Credits。TitleScene 已放在 Build Settings 首位，Credits 已加入构建列表。可单独打开 Credits 进入 Play 检查轮播，也可从 TitleScene 开始完整游戏。

修改图片和布局时请在退出 Play 后保存场景。

原先新建的 StartMenu 场景已删除，现在开始页面统一使用 TitleScene。只需在 Canvas/TitleImage 的 Image → Source Image 拖入标题精灵，即可左右摆动各5°。
