# 第三关 Trace 寻人流程

当前已接入完整第三章：守宫家、街口、巷子、Trace 推理与报平安电话、松鼠家内外屋七张 Letter 线索、Letter 五句初填／五次质询／五处修改、姐妹礼物与信尾、院子收尾及次日事务所。

打开 `Assets/Scenes/Level3.unity` 后进入 Play。场景的 StoryManager 已启用，Override Level Id 为 Level_03；本目录 CSV 与 Resources/LevelData/Level_03 中的导入资源已配置。进入 Play 前现有导表工具会自动同步 CSV。

## 流程

1. 播放台本开场，选择“也就只有那个了吧！”进入调查前对话。
2. 左右移动，任意顺序调查 TR01 门锁／钥匙挂钩、TR02 手机、TR03 纸角。
3. 门锁和钥匙挂钩共用一张证据；笔筒可作为纸角的另一调查入口。已取得的证据不重复发放。
4. 提前点击门垫时提示先核对三处线索；三张证据齐后提示回门垫，进入第二个搜证节点。
5. 点击门垫，在对话内显示有时间与现场锚点的推演插图。推演由对话点击推进，随后返回现场并记录 TR04。
6. 播放准备下楼的对话，然后恢复家中自由查看。再次点击门锁，小毛询问“现在下楼吗？”；选择“下楼看看”切换楼下街口，选择“再看看”返回家中。搜证完成前点击门锁仍是原调查，不会提前出门。
7. 下楼后只能在街口调查花车，取得 TR05。调查对话结束、显示入册提示时自动开始2秒计时，不需点击该提示。之后猫头鹰主动展示08:34的录像，完整对话结束后取得 TR06。此时尚未进入窄巷，也不要求 TR07。
8. 录像结束后小毛询问是否去巷子。选择“去巷子”才切换到窄巷、开放纸片调查；选择“再看看”留在街口。留在街口时点击小毛头像会再次询问，不会重播录像或重启2秒计时。原预览出口不能跳过该选择。
9. 进入窄巷后播放同行调查提示。点击纸片或通风口，取下纸片并与 TR03 拼边，播放08:35—08:39的短推演，取得 TR07；取下后纸片从场景中隐藏。单独点击长凳只给铅笔屑与格栅的提示，不直接发证据。
10. 七张证据齐后出现“整理路线／再看看”。选择整理进入三句初填；选择再看看继续查看现场，之后点击小毛可再次询问整理路线。
11. 初填没有正确率门槛。三次正式质询使用“出示证据”按钮点选证据，无需拖拽；正确卡依次为 TR04、TR02、TR06。错卡回本题，取消出示也回本题，正确后取得 TC1—TC3。
12. 根据证词修改三个关键词，确认妹妹安全并取得地址，随后进入松鼠家。
13. 确认安全后选择“开始调查”。取证用的场景点选仅铅笔橡皮（LT03），门只负责进出与阶段提示。
14. 点击小毛选择“与姐姐交互／再看看”。姐姐提供两个选项：请假与纪念日取得 LT01；礼物与时间安排连续取得 LT02、LT06。
15. LT01、LT02、LT03、LT06 齐全后，妹妹才同意开门。可以进入里间，或暂留外屋后点门／小毛再次询问。
16. 里间点击小毛才出现“与妹妹交互”，自愿交信 LT04 与学校求助 LT05 可任意顺序取得；信件在对话中分段阅读。
17. 两张都取得后，通过门或退出选项回外屋，点击小毛与松鼠核对来访记录取得 LT07。七张齐后询问是否整理心事；选择再看看后，点击小毛可再次询问。
18. Letter 五句初填不设正确率门槛。五次质询依次出示 LT06、LT04、LT04、LT05、LT07，取得 LC1—LC5。第二、第三题分别核对信中的感谢动机与需要／负担。错卡和取消返回本题。妹妹的质询可选先休息，喝水或与松鼠聊后再次征得同意，继续同题，不清空记录。
19. 五处修改逐句保留已通过的答案，错误留在本行。全部正确显示已核对，继续进入姐妹对话。
20. 礼物演出 → 点选信的最后一问 → 院子对话 → 点选小外披 → 点选空纸 → 可选小狗消息 → 把信写完 → 次日事务所 → 第三章完。收尾点选使用对话选项，无新增搜证卡或质询。

暂停游戏会暂停主动录像的计时；切换剧情或停用 StoryManager 会取消旧计时。第三章点击小毛头像使用当前自由查看节点的 AlternateTarget 再次询问；第一、二章头像仍保留原角色切换功能。

手机通电会换成现有低电量精灵；推演目前由现场底图、妹妹立绘和台词组成，没有新增完整逐帧人物动作动画。

## 数据与物件

- `ClueTable.csv`：TR01—TR07、TC1—TC3、LT01—LT07，LC1—LC5，共22张证据与证词。
- `ScriptTable.csv`：388条剧情节点。StageAction=Explore 表示不会自动完成的自由查看阶段；Transition 节点的 HoldSeconds 可配置主动对话延迟。
- `WorldInteractionTable.csv`：按当前保存场景的对象路径绑定，包含钥匙挂钩名称末尾的空格。后续重命名时需同步本表。
- `NavigationTable.csv`：家中搜证仅在守宫家；出门后在街口与窄巷间调查，不能提前去松鼠家。
- `AssemblyTable.csv`：八次正式质询（Trace 三次、Letter 五次），包含专门错卡反馈与默认错误回流。
- `ReasoningTable.csv`：Trace 与 Letter 各有初填和真相两组，共四组；分别为三句话与五句话；真相阶段沿用初填记录。

不要重新运行早期的 Level3 场景重建／套用模板菜单；当前场景已经包含人工摆放的正式图片。

TR06 路口录像不作为世界物件点击，旧占位热点已经关闭。当前用街口底图、妹妹立绘与时间字幕组成对话内静帧展示，尚未加入视频文件或完整人物动作动画。松鼠家的同类展示内容也按对话插入方式接入。
